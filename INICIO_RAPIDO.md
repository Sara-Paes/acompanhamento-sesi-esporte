### 2️⃣ Escolher Modo de Acesso

#### 👁️ Apenas Visualizar (Gratuito)
- Clique em "Apenas Visualizar"
- Veja todas as tarefas e atas
- Sem permissão para editar

#### ✏️ Modo de Edição (Com Senha)
- Clique em "Entrar"
- Digite a senha: `SESIESPORTEAPP`
- Clique em "Entrar"
- Agora pode criar, editar e deletar

### 3️⃣ Criar Primeira Tarefa

1. Clique em "📋 Tarefas"
2. Clique em "+ Nova Tarefa"
3. Preencha os campos:
   - **Tarefa**: Descrição da tarefa
   - **Responsável**: Nome de quem vai fazer
   - **Fase**: Selecione uma fase
   - **Status**: Pendente/Em andamento/Concluída
   - **Data**: Data de criação
   - **Previsão de Entrega**: Quando deve ser concluída
   - **Observações**: Notas adicionais
4. Clique em "Adicionar Tarefa"

### 4️⃣ Registrar Ata de Reunião

1. Clique em "📝 Atas"
2. Clique em "+ Nova Ata"
3. Preencha os campos:
   - **Data da Reunião**: Quando foi a reunião
   - **Participantes**: Quem participou
   - **Alinhamentos**: O que foi discutido
   - **Observações**: Próximos passos
4. Clique em "Registrar Ata"

### 5️⃣ Visualizar Dashboard

1. Clique em "📊 Dashboard"
2. Veja os gráficos de progresso
3. Acompanhe o status das tarefas

## ❓ Perguntas Frequentes

### P: Onde os dados são armazenados?
**R:** No Local Storage do navegador. Cada navegador tem seus próprios dados.

### P: Como compartilhar dados com outra pessoa?
**R:** Use o botão "💾 Backup" para fazer download e compartilhe o arquivo.

### P: Posso acessar de outro computador?
**R:** Sim, mas os dados não sincronizam automaticamente. Use backup/restauração.

### P: E se esquecer a senha?
**R:** Contate o administrador do sistema.

### P: Os dados são seguros?
**R:** Sim, são salvos apenas no navegador. Ninguém tem acesso sem a senha.

## 🆘 Problemas Comuns

### Dados desaparecem após fechar navegador
- **Solução**: Use o botão "💾 Backup" para salvar
- **Alternativa**: Limpe o cache menos frequentemente

### Não consigo editar
- **Solução**: Clique em "Entrar" e digite a senha
- **Verificar**: Você está em modo "Apenas Visualizar"?

### Backup não funciona
- **Solução**: Verifique se o JavaScript está habilitado
- **Alternativa**: Tente em outro navegador

### Arquivo de backup não abre
- **Solução**: Verifique se é um arquivo JSON válido
- **Alternativa**: Contate o administrador
